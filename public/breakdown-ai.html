📋 Breakdown & sheets from your script, with an AI helper

Ten minutes with an AI chat instead of a week with a highlighter — the breakdown plus starter props, costumes, set, and cue sheets.

Glow Tape's Sheets tab can import spreadsheets: the show Breakdown (songs or scenes and who's in each — what powers "pick a song, the right people get called"), plus Props, Costumes, Set, and Light/Sound cue sheets. Making those by hand is the tedious part. If you use an AI assistant (Claude, or any chat that accepts file uploads), it can read your script once and draft all of them — you edit from a running start instead of a blank page.

To be clear: Glow Tape itself doesn't use AI and never sees your script. This all happens in your own AI chat, on your own account. Glow Tape just imports the finished CSV like any other spreadsheet.

How to do it

  1. Open your AI chat — claude.ai works well — and attach your script or score as a PDF.
  2. Paste the prompt below and send it.
  3. Save what comes back as .csv files (most assistants offer them as downloads; otherwise copy each code block into its own file — breakdown.csv, props.csv, and so on).
  4. Import each file into its matching sheet: your show → Sheets tab → pick Breakdown (or Props, Costumes, Set, Light cues, Sound cues) → ⬆ Import CSV. One file per sheet.
  5. Check the character names. Glow Tape matches people by the role/character names in Manage → People & roles — if the import says it didn't recognize someone, spell that role the way the script does (or fix the CSV) and re-import.

The prompt

You're helping a community-theater stage manager prep the attached script for rehearsals. Read the whole script carefully and produce SIX CSV files, each as its own downloadable file (or its own code block). Quote any cell containing a comma. No commentary inside the CSVs. Use character names EXACTLY as the script's character list spells them, everywhere.

FILE 1 — breakdown.csv (the show broken into rehearsal units)
If it's a musical, columns: Song,Act,Pages,On stage,Singing,Dancing,Notes
If it's a straight play, columns: Scene,Act,Pages,On stage,Notes
- One row per musical number (including reprises) or per scene, in show order. For a musical you may add rows for substantial book scenes between numbers.
- Act written consistently ("Act 1", "Act 2"); blank for a one-act. Pages like 12-18.
- On stage: every character in the unit, comma-separated; include "Ensemble" or "Chorus" when called for. Singing/Dancing (musicals): which of those characters do. If unsure whether someone appears, INCLUDE them and add "(check)" to Notes — never silently drop anyone.
- Notes: what an SM would flag — mid-scene entrances/exits, quick changes, offstage voices. Under 300 characters each.

FILE 2 — props.csv
Columns: Item,Scene,Character,Source,Status,Notes
- One row per prop mentioned in dialogue or stage directions. Scene = where it first appears (add more scenes in Notes if it travels). Character = who handles it. Leave Source blank and set Status to "Need". Consumables and food get a note.

FILE 3 — costumes.csv
Columns: Piece,Character,Scene,Source,Status,Notes
- One row per costume piece or look the script explicitly requires or strongly implies (uniforms, period notes, quick changes, weather gear). Note quick changes with the pages involved. Status "Need", Source blank. Don't invent full costume plots — only what the text supports.

FILE 4 — set.csv
Columns: Piece,Scene,Source,Status,Notes
- One row per set piece, furniture item, or scenic element in the stage directions. Status "Need".

FILE 5 — light-cues.csv
Columns: Cue #,Page,Trigger / line,Action,Notes
- One row per lighting change the script explicitly calls for (blackouts, specials, sunrise, act tops/ends). Number them LX 1, LX 2… in order. Trigger = the exact line or action that fires it, shortened. These are placeholders for the designer — mark anything inferred with "(draft)" in Notes.

FILE 6 — sound-cues.csv
Columns: Cue #,Page,Trigger / line,Action,Notes
- Same idea for sound: effects, phones, doorbells, underscoring the script names, pre-show/intermission. Number them SQ 1, SQ 2…

After the six files, tell me separately: any characters from the script's character list who never appear in your breakdown rows, and any pages you couldn't read.
Every file is a draft. The breakdown deserves a real skim against your script before you rely on it for calls — assistants occasionally miss a silent entrance or an offstage voice — and the cue sheets are placeholders for your designers, not a design. Everything is editable in Glow Tape after importing: tap any cell. Only want some of the sheets? Delete the paragraphs you don't need from the prompt before sending it.
Your script is licensed material — only upload what you're licensed to work with, and know that AI chat services have their own data policies. If you'd rather not upload the script anywhere, the same CSV can be typed up in any spreadsheet app: the columns above are all Glow Tape needs.
