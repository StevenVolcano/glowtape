📋 Breakdown from your script, with an AI helper

Ten minutes with an AI chat instead of an evening with a highlighter.

Glow Tape's Sheets → Breakdown can import a spreadsheet of your show's songs or scenes and who's in each one — that's what powers "pick a song, the right people get called" when you schedule. Making that spreadsheet by hand is the tedious part. If you use an AI assistant (Claude, or any chat that accepts file uploads), it can read your script and draft the spreadsheet for you.

To be clear: Glow Tape itself doesn't use AI and never sees your script. This all happens in your own AI chat, on your own account. Glow Tape just imports the finished CSV like any other spreadsheet.

How to do it

  1. Open your AI chat — claude.ai works well — and attach your script or score as a PDF.
  2. Paste the prompt below and send it.
  3. Save what comes back as a .csv file (most assistants offer it as a download; otherwise copy the code block into a file named breakdown.csv).
  4. Import it: your show → Sheets tab → Breakdown → ⬆ Import CSV.
  5. Check the character names. Glow Tape matches people by the role/character names in Manage → People & roles — if the import says it didn't recognize someone, spell that role the way the script does (or fix the CSV) and re-import.

The prompt

You're helping a community-theater stage manager break down the attached script for rehearsal scheduling. Read the whole script carefully and produce ONE CSV.

If it's a musical, use exactly these columns:
Song,Act,Pages,On stage,Singing,Dancing,Notes

If it's a straight play, use exactly these columns:
Scene,Act,Pages,On stage,Notes

Rules:
- One row per musical number (including reprises) or per scene, in show order. For a musical you may also add rows for substantial book scenes between numbers.
- Act: written consistently ("Act 1", "Act 2"). Leave blank for a one-act.
- Pages: the page range in the attached file, like 12-18.
- On stage: every character who appears in that unit, separated by commas, using character names EXACTLY as the script's character list spells them. Include "Ensemble" or "Chorus" when the script calls for them.
- Singing / Dancing (musicals only): which of those characters sing or dance in that number. Leave blank if none.
- Notes: what a stage manager would flag — mid-scene entrances/exits, quick changes, offstage voices, props that travel. Keep each under 300 characters.
- If you're unsure whether a character appears in a unit, INCLUDE them and add "(check)" to Notes — don't silently drop anyone.
- Output the CSV as a downloadable file if you can, otherwise in a single code block. Quote any cell that contains a comma. No commentary inside the CSV.

After the CSV, tell me separately: any characters from the script's character list who never appear in your rows, and any pages you couldn't read.
The AI's draft is a draft. Skim every row against your script before you rely on it for calls — assistants occasionally miss a silent entrance or an offstage voice. The "(check)" notes are where it wants your eyes first. You can edit any unit in Glow Tape after importing.
Your script is licensed material — only upload what you're licensed to work with, and know that AI chat services have their own data policies. If you'd rather not upload the script anywhere, the same CSV can be typed up in any spreadsheet app: the columns above are all Glow Tape needs.
